# Keyboard Shortcuts

## Global

| Key | Action |
|-----|--------|
| `Escape` | Open main menu (press again to close) |
| `Tab` | Switch active panel (left ↔ right) |
| `F1` | Open this Help |
| `F9` | Cycle to next theme |
| `F10` | Quit |

## Navigation

| Key | Action |
|-----|--------|
| `↑` / `↓` | Move cursor |
| `Page Up` / `Page Down` | Move cursor 20 rows |
| `Enter` | Enter dir / open file / browse archive |
| `Cmd+Enter` | Open file with system app |
| `Backspace` | Go to parent directory |
| `Alt+←` | History back |
| `Alt+→` | History forward |

## Panel

| Key | Action |
|-----|--------|
| `Ctrl+=` | Open same folder in other panel |

## Tabs

| Key | Action |
|-----|--------|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close tab |
| `Ctrl+1`–`9` | Switch to tab N |

## Selection

| Key | Action |
|-----|--------|
| `Space` | Toggle selection + move down |
| `Ctrl+A` / `Cmd+A` | Select all |

## File Operations

| Key | Action |
|-----|--------|
| `F2` | Rename (single item) |
| `F4` | Open with system app |
| `F5` | Copy to other panel |
| `F6` | Move to other panel |
| `F7` | New directory |
| `F8` | Delete |
| `Ctrl+M` | Multi-rename — batch rename selected files |

## Viewers & Search

| Key | Action |
|-----|--------|
| `Enter` on text file | Text viewer |
| `Cmd+H` | Hex viewer |
| `Shift+D` | Diff viewer (left vs right cursor file) |
| `D` | Directory sync view (left vs right dir) |
| `Cmd+F` | Find (filename search) |
| `Cmd+G` | Goto (type path with Tab-completion) |

## Display

| Key | Action |
|-----|--------|
| `Ctrl+Q` | Toggle Quick View pane |
| `` Ctrl+` `` | Toggle Command bar |
| `.` button | Toggle hidden files |
| `≡` button | Toggle flat view |

## Process Explorer

| Key | Action |
|-----|--------|
| `F3` | Open Process Explorer |
| `↑` / `↓` | Navigate process list |
| `K` or `Delete` | Kill selected process |
| `Esc` | Close |

## Main Menu

| Key | Action |
|-----|--------|
| `↑` / `↓` | Navigate sidebar items |
| `→` / `←` | Move focus between sidebar and content |
| `Enter` | Activate item |
| `F2` | Rename favorite / remote |
| `Delete` | Remove favorite / remote / custom theme |
| `Esc` | Collapse sub-state → close menu |

## Dialogs (all)

| Key | Action |
|-----|--------|
| `Enter` | Confirm |
| `Esc` | Cancel / close |

## Text Viewer

| Key | Action |
|-----|--------|
| `↑` / `↓` | Scroll line |
| `Page Up` / `Page Down` | Scroll page |
| `Esc` | Close |

## Hex Viewer

| Key | Action |
|-----|--------|
| `↑` / `↓` | Move 16 bytes |
| `Page Up` / `Page Down` | Move one page |
| `Esc` | Close |

## Command Bar

| Key | Action |
|-----|--------|
| `Enter` | Run command |
| `↑` / `↓` | Command history |
| `Esc` | Close command bar |

## Multi-Rename Dialog

| Key | Action |
|-----|--------|
| `Cmd+Enter` | Apply all renames |
| `Esc` | Cancel |

## Archive Mode

| Key | Action |
|-----|--------|
| `Enter` on dir | Descend into directory |
| `Backspace` | Go up one level |
| `Enter` on `..` at root | Exit archive |
| `F5` | Extract selected to other panel |

| Button | Equivalent key | Action |
|--------|---------------|--------|
| `1 Help` | `F1` | Open this Help |
| `2 Rename` | `F2` | Rename |
| `3 Procs` | `F3` | Process explorer |
| `4 Open` | `F4` | Open with system app |
| `5 Copy` | `F5` | Copy |
| `6 Move` | `F6` | Move |
| `7 Mkdir` | `F7` | New directory |
| `8 Delete` | `F8` | Delete |
